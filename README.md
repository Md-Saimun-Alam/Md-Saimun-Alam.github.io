# Md Saimun Alam

PhD student in Physics at the University of Toledo, Biophotonics & AI Lab.
I build deep learning tools for label-free microscopy and biomedical image analysis.

**Website:** https://md-saimun-alam.github.io

## Research
- **CytoMorpheus**: deep learning classification of cancer cell death from label-free phase-contrast and dark-field time-lapse video
- **FRAC**: automated sperm centriole screening with object detection and virtual staining
- **Image-to-image translation**: Pix2Pix and attention U-Net models between phase-contrast and dark-field microscopy
- **Portable and lensless imaging**: on-chip microscopy and 3D-printed optics for point-of-care diagnostics
